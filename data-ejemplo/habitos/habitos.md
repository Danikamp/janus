# Hábitos

Cada hábito tiene un `id` corto (lo que Janus usa para registrar), un nombre
y una cadencia. Edita este fichero a mano cuando quieras añadir o quitar hábitos.

| id        | nombre                  | cadencia | momento | notas                        |
|-----------|-------------------------|----------|---------|------------------------------|
| deporte   | Entrenar               | diario   | tarde   | 30 min mínimo                |
| lectura   | Leer                   | diario   | noche   | 20 páginas                   |
| codigo    | Programar en proyectos | diario   | tarde   | sesión real, no solo leer    |
| sueno     | Dormir antes de las 00  | diario   | noche   |                              |
| ingles    | Inglés                 | 5/semana | mañana  |                              |
