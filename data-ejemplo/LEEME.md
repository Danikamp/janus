# Datos de ejemplo

La carpeta `data/` de verdad (diario, hábitos, proyectos, inbox) no se sube al
repositorio: es personal. Esto es la estructura mínima para empezar.

Primera vez:

```
xcopy /e /i data-ejemplo data
```

Después, borra `data\LEEME.md` y edita `data\habitos\habitos.md` con tus hábitos.
